# 若依 AI 健康档案助手

`ruoyi-ai-health-assistant` 的前端界面，基于若依二次开发，使用 [Vue 3](https://vuejs.org/) + [Element Plus](https://element-plus.org/zh-CN/) + [Vite](https://vite.dev/)。

## 后端项目地址
#### gitee地址
https://gitee.com/zccbbg/ruoyi-fast-service

#### github地址
https://github.com/zccbbg/ruoyi-fast-service

## 前端运行

```bash
# 进入项目目录
cd ruoyi-fast-vue3

# 安装依赖
npm install --registry=https://registry.npmmirror.com

# 启动服务
npm run dev

# 前端访问地址 http://localhost:80
```

## 主要功能

- 按家庭成员浏览健康资料，并通过 AI 问答查询档案内容和引用来源。
- 上传 PDF 或图片报告，核对识别草稿，查看健康指标趋势。
- 配置问答与报告识别模型，查看历史会话。
- 使用用户、通知公告、字典、参数和日志等后台管理功能。

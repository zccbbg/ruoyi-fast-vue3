## 前端运行

```bash
# 进入项目目录
cd ruoyi-fast-vue3

# 安装依赖
npm install --registry=https://registry.npmmirror.com

# 启动服务
npm run dev

# 构建测试环境 yarn build:stage
# 构建生产环境 yarn build:prod
# 前端访问地址 http://localhost:80
```

## 内置功能

1. 用户管理：配置系统用户。
2. 字典管理：维护系统使用的字典类型和字典数据。
3. 参数管理：维护系统配置参数。
4. 在线用户：查看当前登录用户并支持强退。
5. 操作日志：查询系统操作记录。
6. 登录日志：查询登录记录和异常登录。
